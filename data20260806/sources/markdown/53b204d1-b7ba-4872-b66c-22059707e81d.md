# 第一章 总则
第一条为了规范公司的考勤管理，明确考勤奖惩规定，特制订本制度。第二条本制度适用于“万户软件”全体员工。

# 第二章 工作时间
第三条公司实每周五天、每天小时、每周四十小时作制。每日工作时间9：00-18：00，其中12：10-13：10为午餐和休息时间。上班打卡时间晚于9：00，在9：30前的不记迟到或请假，下班时间须顺延晚到时长。
# 第三章 考勤方式
第四条考勤式按照部、岗位的不同分为坐班岗位、移动考勤岗位两种，两种岗位考勤式 不同。
（一）坐班岗位：上、下班指纹考勤机考勤，无考勤机的办公室手机移动考勤。
（二）移动考勤岗位：“机移动考勤”（客户现场）结合“指纹考勤机考勤”（公司）两种方式；
（三）坐班岗位包括：营销中及项中岗，如财务、事、政、商务、助理、驻场 运维等不需要经常出差的岗位。
（四）移动考勤按工作性质以及出差形式的不同分为2种：
1．需要发起“移动考勤策略备案”的岗位：研发、测试、实施、驻场运维、技术支持等。
2.不需要发起“移动考勤策略备案”的岗位：销售、售前、产品等。

# 第四章 考勤要求
第五条公司实行上下班考勤制，即每日考勤记录须包括上班时间、下班时间。如在客户现场，按到达和离开客户现场的实际时间打卡。如遇特殊情况如停电，实行签到制；如遇考勤设备故障需要在0A提交邮件说明，经部门主管同意后由行政考勤专员记入考勤报表。
严禁员工代考勤。
第六条员工无论请任何类型的假都必须提前在0A里提交“请假申请”流程，审批结束后至人政部存档。“请假”流程中必须注明请假原因，否则审批有权不予准假。部门主管无法及时审批的，请假人须通过电话经得部门主管的同意后方可不到岗。如电话联系不上部门主管的，则电话联系隔级领导说明情况并得到允许后方可离岗。

第七条特殊情况的病假、事假（突发事件)不能及时提交“请假”流程的，应在当天上班前电话向部门主管请假，如电话联系不上部门主管的，则电话联系隔级领导。上班后及时补办“请假”流程，没有流程的按旷工处理。
第八条员工假期届满需要续假须电话向部门主管申请续假，如电话联系不上部门主管的，则电话联系隔级领导。上班后及时补办“请假”流程，否则超假部分按旷工处理。第九条员工假期未满提前返回公司上班的，按正常方式考勤，人力行政部将根据考勤记录调整员工请假时间。
第条因公出差须先经部门主管同意后在0A办理“出差申请”流程。出差流程不再需要逐级审批，保留部门主管和人力政部备案。员工须如实填写出差时间和地点等信息。若发现信息作假或 不符合工作实际情况等视为严重违反公司规章制度。
第一条办理病假流程的（含特殊情况病假），3天以内（包括3天）的病假需出具区级以上.医院的个人病历卡及医生关于休假时间的书面建议，超过3天的病假需提供三甲及以上医院开具的盖有医院公章的证明，否则审批人有权不予准假。
第条如因作需要上午未到公司直接去办事的，按照岗位不同，“坐班岗位”须在前天下班前提交“申请不刷卡”流程；如前一天未能提交流程的，经部门主管邮件证明后，由行政考勤专员按照“半天调休或事假抵一次不刷卡”在考勤报上体现，无邮件按照旷工处理。“移动考勤岗位”需提前一天下班前在OA提交“移动考勤备案申请流程”，到客户现场后移动考勤。第三条 员上班时间外出办事需要经得部门主管或隔级领导同意，并在前台“外出登记表”中登记进登记。因私外出必须办理请假续。如私外出，经发现按早退或旷处理。 
# 第五章 考勤细则
第十四条上班中途请假，按实际到司时间及离司时间考勤。如某员工某日11：00-15：00请假，
即其当日的工作时间为上午8：30-11：00、下午15：00-18：00，系统内应有四次考勤记录；如8：30-12：00请假，即当日正常工作时间为13：30-18：00，则系统内应有两次考勤记录。
坐班岗位上班打卡时间晚于9：00，在9：30前的不记迟到或请假，下班时间须顺延晚到时长。
打卡时间晚于9：30的，可以申请调休或请假。
实施、研发、测试等出差或外出客户现场的，按到达和离开客户现场的实际时间打卡2次（原则为上下午各1次），不记迟到、早退等。
第十五条因不可抗力因素造成无法按照制度要求执行，不在此制度范围内，按照实际情况另行处理。
第十六条每位员每日、每的出勤情况可在0A系统考勤模块中查看，人力行政部不再另通知，有异常的记录的须及时补办。
第十七条每月初人力行政部根据考勤模块中的数据制作上月的考勤报表，有异常记录的须在每月8号前完成流程的补办，否则无法计入上月考勤结果。第条每位员每最多可在0A上发起两次“不刷卡申请流程”，适用于特殊情况未考勤（忘记考勤、网络问题、手机出问题等）。超过两次的不刷卡申请流程，考勤专员制作考勤时将按照作废流程处理。或经由本邮件申请后按照“半天调休或事假抵一次不刷卡”处理。

# 第六章 移动考勤
第九条 使移动考勤，须做“移动考勤策略备案申请”。
（一）可在出差流程中填写出差地点及移动考勤策略信息，系统将自动生成移动考勤策略，无须再单独发起备案流程。
（二）在市内到客户现场作的，可发起“移动考勤策略备案申请”流程。
（三）具体填写说明如下：
1．“移动考勤备案流程”里需选择对应的项目名称、考勤开始时间、考勤结束时间；项目的度”、“纬度”栏便带出相应地址信息。
2.如果申请人申请的移动考勤项目有多个办公地点，那么就需要为此项目申请多个移动考勤备案。以便在系统中生成多个考勤策略。
（四）移动考勤策略备案申请流程不再设置逐级审批，保留部门主管和人力行政部备案。员工须如实填写备案地点、时间等信息。若发现信息作假或不符合工作实际情况等视为严重违反公司规章制度。
第二十条使用移动考勤的特殊情况（）上、下班时间因为在出差途中而无法移动考勤的，可发起“不刷卡申请流程”，考勤
专员结合“出差申请流程”内的时间进核实。此流程不含在“两次“不刷卡申请流 程””之内。
（二）如因为在“移动考勤备案申请流程”无法定位客户地址或者在客户现场无法定位等技术原因导致无法考勤，可写0A邮件至上级经理及所属公司人力行政部说明情况。由上级经理邮件回复证明，人力政部核实后记录考勤。此类情况须在两个工作日内说明情况，否则视为旷工。
# 第七章 请假
第十条请假类型分为事假、病假、婚假、产假、陪产假、哺乳假、丧假、年休假。
第二十二条事假为无薪假。事假的最小单位是1小时。事假扣款规则为：月度工资标准/21.75/8*事假小时数。
第二十三条病假的最小单位是半天；3天以内（包括3天）的病假需出具公医院（包含社区医院）的个人病历卡；3天以上的病假需提供三甲及以上医院开具的盖有医院公章的休假证明，无病历或休假证明并且已经休假的按事假处理。
（一）病假为带薪假，病假工资为工作地当地最低工资标准的80%。
（）员年累计或连续病假满15个作（病除外），再次请假时公司会根据该员工的身体实际情况，经协商后为该员工调换岗位或采取其它处理办法。公司有权对员工医疗记录的真实性进行检查，员工应当配合。员工拒绝检查并借故病假不上班的，公司有权驳回病假申请。员病假期间应静养病，不得外出游玩，参加培训，或从事与疾病不符的事务。一经发现，按照严重违纪的规定处理。
第二十四条 婚假为全薪假，3天；员工劳动关系所在地对于婚假天数有特殊规定的，依据该特殊规定执行。婚假须在领取结婚证后的6个月内享受，必须提前一周与部门主管申请；婚假时间按自然天数计算，即为历天数，遇节假不顺延；婚假必须次性休完（特殊情况需另申请）。需提供：结婚证。
第二十五条产假，符合国家生育政策的依法享受，产假由社保统筹基金报销相关医疗费和发放生育津贴，公司不再重复发放产假薪资。产假98天；难产增加15天；生育多胞胎的，每多生育一个婴儿，增加15天；员工劳动关系所在地对于产假天数有特殊规定的，依据该特殊规定执行。产假时间按自然天数计算。需提供：结婚证、准生证。
第十六条 陪产假为全薪假，符合国家育政策的依法享受陪产假，否则按事假处理；休假时
间依据职工劳动关系所在地人口与计划生育条例的规定执行。陪产假时间按自然天数计算。需提供：
结婚证、准生证。
第七条 哺乳假为全薪假，有不满周岁婴的员公司在每天作时间内给予其哺乳时间：每天两次半时或每天次一时，有效期6个。假期天数按然天数计算。本条适用在产假结束后即返司正常工作的情况。
第条丧假为全薪假，3天。亲属范围为母、、祖母、孙、外祖母、外孙、兄弟姐妹、配偶、岳母、公婆。丧假时间按然天数计算。
第二十九条年休假，详见公司年休假相关制度。

# 第八章 加班调休
第三十条 加班
（）公司不提倡必要的加班，员应在每作时间内完成作任务。加班申请流程只适用于公休日和节假日。加班时间可兑现调休，且可累计进行。
（二）加班最小单位两小时；超过部分超过半小时不满一小时的按半小时处理，不满半小时
的按零处理；如某员工某日申请加班时间为8：30-10：30，考勤记录显示8：30-11：15，经其部门主管确认后该员工加班工时为2小时30分。
（三）必须由本提前向部门主管提出申请，经部门主管同意后，在0A提交“加班申请” 流程，经隔级领导审批后方可视为加班；
（四）部门主管需要根据实际情况判断是否有加班必要，并对员工的实际加班时间进行评估； 统计加班工时结合实际考勤记录，以其部门主管确认的有效时间为准。如无考勤记录，需在流程中说明无考勤记录的原因，否则“加班申请”流程视为无效；
（六）统计加班时需根据加班的实际情况扣去午餐及休息时间（1时30分钟）、晚餐时间（30分钟）；如特殊情况午休及晚餐时间仍在工作的，需要在提交“加班申请”流程时注明“未就餐”。
（七）除法定节假日的加班按三倍统计加班工时外，其余均按实际加班时间统计加班工时。
（八）适用于全公司；
第三条 调休
（）调休的最单位为1时；
（二）连续调休原则上不可超过24小时，超过24小时以上的连续调休需由分管领导审批；

（三）每累计调休不可超过40时，超过40时的调休需提前一周向部门主管、分管领导提出申请，并由总经理特批后方可进行；
（四）当年的加班时间有效期截止至次年的6月30日；即当年未休的加班时间次年的7月1日起自动放弃；
（五）员工必须提前在OA中提交“调休”流程，得到部门主管批准后方可进行调休（如遇工作繁忙，部门主管有权拒绝，另安排时间调休)。
（六）政部在审批“调休”流程时必须确认该员“加班时>=调休时”，否则 多出的部分按事假处理。第三十二条 如因个人原因造成工作不能按时完成而加班的，不作加班处理。第三三条加班调休按进统计，每政部根据OA系统中的“加班”、“调休”流
程、实际考勤记录、以及部门主管确认的有效加班时间进行加班、调休工时的核实与统计；并在次月10公布在OA系统中，部主管、员工本可在0A系统中查看。第三十四条加班调休制度适用于全公司。

# 第九章 薪资定义与奖罚
第三十五条每日薪资=月工资/21.75（劳动法规定每月的平均计薪工作日为21.75天）。
第三十六条 每时薪资=资/21.75/8。 
第三十七条 旷工按事假的三倍处理，年内旷达三次者，按自动离职处理。第三十条旷工三天及以上，按正常离职处理。第三十九条代考勤对当事人各罚款100元，并视为严重违反公司规章制度。第四十条公司提倡信任化，相信每位员能够如实考勤，若发现不符合实际工作情况等作假为，视为严重违反公司规章制度，公司将对当事人做辞退处理。
# 第十章 名词解释
第四十一条请假是指请求准假，请求领导同意准假，而通知领导需要请假。第四十条 旷工是指工作时间内未经部门经理批准而擅离职守者，以及未办理请假手续或请假未被批准而擅自缺勤。
（一）旷工包括但不限于以下情况：
1.员工在应出勤的时段内无考勤记录且旷工事实成立；
2.休假超过批准的假期截止日期没有经审批同意的续假所产生的缺勤；
3.提供虚假证明或伪造、变造、涂改休假证明后获得的休假；
4.在工作时间内不服从工作、培训安排的；
5.工作期间擅自离岗，做旷工处理，离岗时间可做旷工累计；
6.迟到、早退超过规定时间1小时以上的。

(）旷按事假的三倍处理，年内旷达三次者，属于严重违纪，按动离职处理。
（三）旷三天及以上，属于严重违纪，按正常离职处理。
第四十三条迟到是指员工在没有事先办理请假手续的情况下没有按公司规定的时间上班午休后不按时到岗者，也按迟到处理。
第四十四条早退是指员工在没有事先办理请假手续的情况下没有按公司规定的时间下班；未到午休时间提早餐，也按早退处理。
第四五条不可抗，是指由于地震、灾、灾、车祸、暴风雪或其他不可抗原因造成
为能力不可控或根本无法按要求实现的情况。
第四十六条法定节假，根据国家法律法规统一规定的休假时间。第四七条动离职，具体见《员工离职管理规定及续办理程序》。第四条正常离职，具体见《员离职管理规定及续办理程序》。
第章附则第四十九条本制度不适于层管理员，总经理、副总经理等不参与考勤。第五十条本制度经总经理批准后，自颁布之起执。
第五十一条本制度解释权在人力行政部。
