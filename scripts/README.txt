Wiki-Brain 使用说明
====================

一、目录结构
------------
本目录是可以直接运行的发行包，包含：

  wiki-brain-server(.exe)   主程序（单一可执行文件，静态资源已内置）
  config/                   运行时配置（可编辑，程序按相对路径读取，
                            请勿与主程序分离存放）
  logs/                     程序日志输出目录（首次启动自动写入）
  data/                     数据库、全文索引、上传文件存放目录（首次
                            启动自动创建，此目录包含全部业务数据，
                            备份/迁移只需要复制这一个目录）

  # Linux / macOS 包额外包含：
  run.sh                    启动/停止脚本

  # Windows 包额外包含：
  service.ps1 / service.bat 注册为 Windows 服务的管理脚本（依赖 NSSM，
                            见下文「Windows：注册为系统服务」）

程序监听端口默认为 8800，如需修改，编辑 config/config.yml 中
server.port 一项后重启。


二、启动 / 停止
----------------

【Linux / macOS】

在本目录下执行：

  ./run.sh start      启动服务（后台运行，日志见 logs/）
  ./run.sh status      查看运行状态
  ./run.sh stop        停止服务
  ./run.sh restart     重启服务

首次使用如提示无执行权限，先执行一次：

  chmod +x run.sh wiki-brain-server


【Windows】

最简单的方式——双击 wiki-brain-server.exe 直接运行，此时程序占用当前
窗口（前台运行），关闭窗口即停止服务，适合临时试用。

如果需要开机自启、无需登录、后台常驻运行，参考下面的「注册为系统
服务」。

  Windows：注册为系统服务
  ------------------------
  依赖 NSSM（https://nssm.cc/），请把 nssm.exe 下载后放到本目录（与
  wiki-brain-server.exe 同级）。以管理员身份打开命令行，在本目录下：

    service.bat install     注册服务（首次执行）
    service.bat start       启动服务
    service.bat status      查看运行状态
    service.bat stop        停止服务
    service.bat uninstall   卸载服务

  也可以双击 service.bat（不带参数默认查看状态，会自动弹出管理员权限
  申请窗口）。


三、访问系统
------------
服务启动后，在浏览器中打开：

  http://<服务器地址>:8800/

本机运行可直接访问 http://localhost:8800/ ；部署在远程服务器上则把
<服务器地址> 换成该服务器的 IP 或域名，并确认对应端口的防火墙/安全组
已放行。

系统内置了详细的用户手册，登录后可在页面内打开，或直接访问：

  http://<服务器地址>:8800/help


四、首次使用：三步开始
------------------------

第 1 步：配置模型（必须，否则无法导入文件和检索）
  1. 点击左侧导航栏齿轮图标「系统设置」
  2. 在「模型服务商配置」区域点击「新建服务商」，选择平台（阿里云百炼/
     火山方舟豆包/智谱AI/Kimi/DeepSeek/vLLM/Ollama/OpenAI 兼容 等），
     填写该服务商的 Base URL 和 API Key
  3. 保存后点击「测试」确认能正常连通、能拉取到模型列表
  4. 在「用途绑定」区域，至少给「默认」这一项绑定刚配置好的服务商和
     具体模型（推理/提取/分类/文档转换 等其余用途留空时会自动回退到
     「默认」，不强制逐项配置）
  5. 点击「保存绑定」

第 2 步：创建知识领域
  1. 点击左侧导航栏「知识领域」
  2. 左侧领域列表下方点击「+ 新增领域」
  3. 填写领域名称（例如：合同与采购管理），确认创建

第 3 步：导入文件
  1. 在「知识领域」页面选中刚创建的领域
  2. 点击（或拖拽文件到）上传区域，支持 MD / TXT / PDF / DOCX /
     PPT・PPTX / XLS・XLSX
  3. 文件会进入后台异步处理（解析 → 知识点提取），处理进度可在页面上
     查看；处理完成后即可在该领域下进行检索提问

以上完成后即可开始正常使用。更详细的功能说明（Wiki 编译、激活链接、
学习报告等）请参考系统内置用户手册（见上文「三、访问系统」）。
