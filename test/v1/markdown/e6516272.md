# 1. 中间件配置
## 1.1. 检查 JDK 版本
命令行中执行 java -version 检查系统环境默认的 jdk 版本，目前 OA 和 FLEXBASE 系统支持 JDK1.8
信创环境普遍使用 OPENJDK，建议使用最新的 1.8 版本，需要安装 JDK 完整版本，而非 JRE 版本
## 1.2. 东方通7
### 1.2.1. JAVA 参数设置
Tongweb/bin/external.vmoptions
```
# JVM 内存大小，系统内存足够的情况下建议设置
# Xms JVM 堆内存最小值，Xmx JVM 堆内存最大值
# MetaspaceSize JVM 元数据库空间大小，存储 java 代码
-Xms8192m
-Xmx8192m
-XX:MaxMetaspaceSize=1024m
-XX:MetaspaceSize=512m
# 禁用 spring 框架中的 jmx 服务（针对flexbase 产品）
-Dspring.jmx.enabled=false
# 禁用东方通的 JPA （针对flexbase 产品）
-DenableJPA=false
# 设置文件编码为 UTF8，影响 JAVA 对文件和控制台流的读写
-Dfile.encoding=UTF-8
# 设置 JAVA 时区为中国
-Duser.timezone=GMT+08
# 设置东方通中间件只使用 web 模块
-DWebModuleOnly=true
# 禁用 DEBUG
#-Xrunjdwp:transport=dt_socket,server=y,suspend=n,address="$2"
```

# 2. 数据库配置
## 2.1. 达梦
### 2.1.1. 参数配置

| 参数 | 建议值 | 说明 |
| --- | --- | --- |
| MAX_SESSION_STATEMENT | 20000 | 每个会话打开的最大句柄数 |
| MAX_SESSION | 2000 | 系统允许同时连接的最大数，同时还受到LICENSE的限制，取二者中较小的值，有效值范围（1~65000 ） |
| ENABLE_MONITOR | 0 | 1 开启性能监控，0 关闭性能监控 |
| SVR_LOG | 0 | 关闭记录 SQL 语句日志 |

### 2.1.2. 基本信息查询
```
查询页面大小
select path,page_size from v$datafile;
查询字符集（ 0 表示 GB18030，1 表示 UTF-8，2 表示 EUC-KR，数据库字符集要求为 UTF-8）
select  UNICODE();
查询大小写（ 0 表示 大小写不敏感，1 表示 大小写敏感）
select SF_GET_CASE_SENSITIVE_FLAG();
查询数据库版本
select * from v$version;
```

## 2.2. 人大金仓
### 2.2.1. 参数配置

| 参数 | 建议值 | 描述 |
| --- | --- | --- |
| max_connections | 2000 | 数据库允许的最大连接数。此值应该根据实际应用情况设置，设置的越大对 shared_buffer 消耗的就越大 |

```
ksql 命令登录数据库后执行
show case_sensitive;
查询数据页面大小
SELECT current_setting('block_size');
查询数据库版本
select version();
```
